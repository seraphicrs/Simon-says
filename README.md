# Simon Says Game

A simple and interactive **Simon Says** memory game built using **HTML, CSS, and JavaScript**. The game challenges players to remember and repeat an increasingly long sequence of colors. Each successful round adds a new step, testing your memory and concentration.

## Features

* 🎨 Colorful interactive game buttons
* 🧠 Randomly generated sequences
* 💥 Game Over screen with restart option
* ⚡ Smooth button flash animations
*   Easy to play and Interactive 

## Built With

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 🎯 How to Play

1. Press any key to start the game.
2. Watch the button that flashes.
3. Click the same button.
4. Repeat the complete sequence in the correct order.
5. A new color is added each round.
6. Make a mistake, and the game ends.
7. Press any key to play again and try to beat your highest score.
